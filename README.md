# LifeTimerWidget ⏳

LifeTimerWidget は、あなたの「残り寿命」を可視化する Android 用のウィジェット＆カウントダウンアプリです。
「人生の残り時間」を意識することで、1日1日を大切に生きるためのモチベーションを提供します。

## 📸 機能概要

- **ホーム画面ウィジェット**: ホーム画面に残り寿命（年・日・時間・分・秒）を表示し、いつでも人生の残り時間を確認できます。（※バッテリー節約のため、秒単位のリアルタイム更新はアプリ内でのみ行われます。ウィジェットは「更新」ボタンで最新化できます。）
- **リアルタイムカウントダウン**: アプリを開くと、毎秒リアルタイムで減少していく残り寿命を確認できます。
- **カスタマイズ機能**: 自身の「生年月日」と「想定寿命（歳）」を自由に設定可能です。

## 🛠️ 使用技術・アーキテクチャ

本アプリは、モダンな Android 開発技術と、**「ミノ駆動設計（堅牢なオブジェクト指向設計）」** を厳格に適用して開発されています。

- **言語**: Kotlin
- **UI フレームワーク**: Jetpack Compose
- **ウィジェット**: Jetpack Glance
- **設計思想のハイライト**:
  - **値オブジェクト (Value Object) の徹底**: 日付や時間を単なる `Long` や `Int` などのプリミティブ型で回さず、`BirthDate` や `LifeExpectancy`、`RemainingLife` などのドメインオブジェクトとしてモデリング（プリミティブ型執着の排除）。
  - **完全コンストラクタと不変性 (Immutability)**: オブジェクトは初期化時にバリデーション（早期リターン・ガード節）を行い、状態はすべて不変 (`val`) に保つ設計。
  - **高凝集なドメインロジック**: 寿命の計算ロジックなどをUI側（表示側）に漏洩させず、データを保持する `LifeTimer` ドメイン自身に振る舞いを持たせる「尋ねるな、命じろ」の原則を適用。

## 🚀 ビルド手順

1. リポジトリをクローンします。
2. Android Studio でプロジェクトを開くか、以下の Gradle コマンドを実行します。
```bash
./gradlew assembleDebug
```
3. 生成された APK (`app/build/outputs/apk/debug/app-debug.apk`) を Android 端末にインストールしてください。
